Definition: Encapsulation is the process of bundling data (variables) and methods into a class and controlling access to the internal data.

Purpose:

- Protection: Prevents direct, unauthorized access to data using `private`.
    
- Boundaries: Enforces rules to prevent invalid values.
    
- Control: Allows access through getters and setters.
    
- Flexibility: Internal implementation can change without necessarily breaking other code.
    

Example:

```
class BankAccount {
    private double balance;

    public void deposit(double amount) {
        if (amount > 0) {
            balance += amount;
        }
    }

    public double getBalance() {
        return balance;
    }
}
```

Key points:

- `private` → protects internal data.
    
- Setter → controls how data is modified.
    
- Getter → controls how data is accessed.
    
- Validation → enforces boundaries.
    

Remember: Encapsulation = bundling data and methods + controlling access to data

2) To avoid the "Infinite Russian Doll problem "
When a data structure contains a field of its own type, and a language tries to store that value directly inside itself rather than through a reference.

Java

```
class Person {
    String name;
    Person bestFriend;
}
```

When the computer tries to allocate memory for a `Person`, it must first calculate how many bytes a `Person` needs:

$$\text{Size}(\text{Person}) = \text{Size}(\text{name}) + \text{Size}(\text{Person})$$

To resolve the size of that inner `bestFriend` (`Person`), it has to evaluate the size again:

$$\text{Size}(\text{Person}) = \text{Size}(\text{name}) + \big(\text{Size}(\text{name}) + \text{Size}(\text{Person})\big)$$

This substitution never stops. Inside the first doll is a second doll; inside the second doll is a third doll; inside the third is a fourth, repeating down to infinity.
### How Object References Solve It

An object reference breaks the infinite loop by separating the **size of the remote** from the **size of the object**.

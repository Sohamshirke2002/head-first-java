## One more thing: Java even lets you skip `new` in certain cases

You can write:

```
int[] nums = {10, 20, 30, 40, 50, 60, 70};
```

This is valid Java!

Java creates and initializes the array for you. You don't explicitly write `new int[7]`, but an array object is still created behind the scenes.


==So java does this array like allocation because it can use it for dynamic allocation==
